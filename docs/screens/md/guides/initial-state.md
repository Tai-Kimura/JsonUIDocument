# InitialState - Initial state and the state bridge

## Overview

Guides > Initial state. Dedicated page for a test's initialState and the state bridge (jsonui-test-runner v1.14.0 spec §10; drivers iOS 1.15.0 / Android 1.17.0 / web 1.15.0, SwiftJsonUI 10.30.0, KotlinJsonUI 2.44.0, jsonui-cli 1.9.34). Ten sections: what it does and the release it needs, how to write it (file level, case level under caseIsolation reopen, the shallow merge), keys and the class table with the fixed rejection reasons, when the app applies the values and the gate it shares with the screen marker, the receipt the driver waits for and where the bridge lives per platform, reading state back without a provider, flows (viewModels, the removed initialState.screen, ignored references), the launch sequence and the web runner's afterLaunch, what validate checks (output measured on 1.9.34), and what it does not cover. ~11-min read.
